# 大乐透预测方法测试脚本 - 需求文档

## 项目概述

本项目旨在开发一个全面的预测方法评估系统，通过自动化测试现有的大乐透预测算法，找出最有效的中奖预测方法。系统将持续运行不同的预测算法，直到获得一等奖或二等奖为止。

## 核心需求

### 1. 预测方法调用
- **接口调用**: 自动调用现有CLI接口 `python3 dlt_main.py predict -m [method] -p [periods] -c [count]`
- **方法支持**: 支持所有现有预测方法
  - 传统方法: frequency, hot_cold, missing
  - 高级方法: markov, markov_2nd, markov_3rd, adaptive_markov, bayesian, ensemble
  - 深度学习: lstm, transformer, gan
  - 复合方法: compound, duplex, markov_compound, nine_models等
- **参数配置**: 
  - periods: 10-2000期历史数据
  - count: 1-10注预测号码

### 2. 中奖等级判断
- **开奖数据**: 从 `data/dlt_data_all.csv` 获取最新开奖结果
- **中奖规则**: 实现完整的大乐透中奖等级判断
  - 一等奖: 前区5中5 + 后区2中2
  - 二等奖: 前区5中5 + 后区2中1
  - 三等奖: 前区5中5 + 后区2中0
  - 四等奖: 前区5中4 + 后区2中2
  - 五等奖: 前区5中4 + 后区2中1 或 前区5中3 + 后区2中2
  - 六等奖: 前区5中4 + 后区2中0 或 前区5中3 + 后区2中1 或 前区5中2 + 后区2中2

### 3. 测试策略
- **基础测试**: 对每种方法进行初始参数测试
- **累进测试**: periods从10递增到2000的渐进式测试
- **随机测试**: 随机参数组合的优化测试
- **停止条件**: 获得一等奖或二等奖时自动停止

### 4. 结果记录与分析
- **测试日志**: 记录每次测试的详细信息
  - 预测方法
  - 参数配置(periods, count)
  - 预测号码
  - 中奖等级
  - 测试时间
- **统计分析**: 
  - 各方法的中奖率统计
  - 不同参数下的表现对比
  - 最优方法推荐

## 功能规格

### 输入规格
- **配置文件**: 测试参数配置
- **数据源**: 历史开奖数据文件
- **CLI接口**: 现有预测系统接口

### 输出规格
- **实时日志**: 测试过程的实时输出
- **结果报告**: JSON/CSV格式的详细测试结果
- **统计图表**: 各方法表现的可视化分析
- **最终推荐**: 最佳预测方法和参数建议

### 性能要求
- **并发支持**: 支持多方法并行测试
- **中断恢复**: 支持测试过程的暂停和恢复
- **内存优化**: 合理控制内存使用
- **错误处理**: 完善的异常处理机制

## 技术架构

### 1. 核心模块
- **PredictorCaller**: CLI调用和输出解析
- **LotteryJudge**: 中奖等级判断引擎
- **TestController**: 测试流程控制
- **ResultRecorder**: 结果记录和分析
- **ConfigManager**: 配置管理

### 2. 数据流
```
测试配置 -> 预测调用 -> 结果解析 -> 中奖判断 -> 结果记录 -> 统计分析
```

### 3. 扩展性
- 模块化设计，易于添加新的预测方法
- 配置化的测试策略
- 插件式的结果分析器

## 风险与约束

### 技术风险
- CLI接口输出格式变化
- 深度学习方法计算时间较长
- 大量测试可能影响系统性能

### 约束条件
- 基于现有预测系统，不修改核心预测逻辑
- 测试结果仅供学术研究，不用于实际投注
- 遵守相关法律法规
